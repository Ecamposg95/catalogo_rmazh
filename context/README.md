# Contexto del Proyecto

Este directorio concentra la información necesaria para entender, operar y modificar el catálogo sin tener que inferir la estructura desde los archivos.

## Documentos

- `arquitectura.md`: mapa de carpetas y responsabilidades.
- `flujo-operativo.md`: pasos para actualizar productos e imágenes.
- `contrato-datos.md`: columnas esperadas en el Excel y cómo se consumen en frontend.
- `decision-reestructura.md`: cambios realizados en esta reorganización.
